UNO R4 WiFi bridge firmware 0.6.0, built from Arduino's source here. It
has **no changes** from Arduino's code. It is the known-good baseline for
this fork, and the image to go back to if a later fork build misbehaves.

> [!IMPORTANT]
> This is a **self-built image of Arduino's 0.6.0 source, not Arduino's
> own binary.** The build compiles its own file paths into the firmware,
> so the bytes differ from Arduino's file by a few hundred bytes. The
> behavior is the same, and the board reports itself as 0.6.0.

## What is in this release

| File | What it is |
|---|---|
| `UNOR4-WIFI-S3-0.6.0-stock.bin` | The ESP32-S3 flash image (bootloader, partition table, otadata, certificate bundle, app), 1966080 bytes. This is the `S3-BOOT-APP.bin` the build produces, renamed. It is the exact file that was flashed to a UNO R4 WiFi and checked on 2026-10-22. |
| `SHA256SUMS` | Its SHA256 checksum. |

```
73f33387ef6a21fe8264efdcb4e48d50e5f69e51fdb9d85345654cabcc20e423  UNOR4-WIFI-S3-0.6.0-stock.bin
```

Flashing this image leaves the board's saved settings (NVS, including
WiFi credentials) untouched, the same as Arduino's own updater.

## How to flash it

Follow **Step 5** of the
[procedure](https://github.com/TonyMarkham/unor4-wifi-interrupt-bridge/blob/v0.6.0-stock/docs/build-original-procedure.md),
including the backup in 5.4. Do not skip the backup.

The only difference: in 5.5, use the path of the file you downloaded
instead of the build output's `S3-BOOT-APP.bin`.

Before flashing, check the download. In the folder that holds both files:

```
sha256sum -c SHA256SUMS
```

It must print `UNOR4-WIFI-S3-0.6.0-stock.bin: OK`. If it prints anything
else, do not flash the file.

> [!WARNING]
> Flash this file only at address `0x0`, with espflash 2.0.0, exactly as
> step 5.5 shows. Do not use the esptool command in Arduino's README:
> its offsets do not match this board's partition layout.
